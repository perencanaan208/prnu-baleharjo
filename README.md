# 🕌 Website Resmi PRNU Baleharjo

Website resmi Pengurus Ranting Nahdlatul Ulama (PRNU) Desa Baleharjo, Kecamatan Sukodono, Kabupaten Sragen, Jawa Tengah.

## 🌐 Live Website
Deploy via Vercel — otomatis update setiap push ke GitHub.

## 🛠️ Teknologi
- **Frontend**: HTML + Tailwind CSS + Vanilla JS
- **Backend**: Google Apps Script (GAS)
- **Database**: Google Spreadsheet
- **Hosting**: Vercel (static)
- **CDN**: Cloudflare (opsional)

## 📁 Struktur File
```
prnu-baleharjo/
├── index.html      # Seluruh aplikasi web (SPA)
├── vercel.json     # Konfigurasi Vercel
└── README.md       # Dokumentasi ini
```

## ⚙️ Konfigurasi Backend (Google Apps Script)
Website ini terhubung ke Google Spreadsheet via GAS.
Script GAS tersimpan terpisah di Google Apps Script Editor.
